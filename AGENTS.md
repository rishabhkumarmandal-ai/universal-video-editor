# Editing workspace

This directory is the user's reusable video-editing repository. For a new video edit or a revision to this style, read `skills/universal-video-editor/SKILL.md` and use that skill automatically. The user's accepted default is blue/black/grey, solid headshot icon backgrounds, readable word-matched Roman Hinglish captions, clean UI cutaways and conceptual motion graphics. Explicit new requests override defaults.

Default authorized workflow: inspect source → draft/review transcript → write and share concrete plan → continue editing → render/verify → deliver. Do not stop after the plan or ask for routine render approval when the request is end-to-end. Honor transcript-only, analysis-only, plan-only or preview-only limits. Ask about material speech ambiguity while continuing independent work; don't invent the answer.

New jobs go in `jobs/<name>/`, which is ignored by Git. Preserve original footage, all old exports and reference videos. Existing `stackvideo-edit`, `local-edit`, `blue-grey-edit` and `.editing-tools` are retained local project/runtime history; their old orange instructions and hardcoded Stackvideo/GitHub scripts are not the reusable defaults. Never run those old project generators against a new video.

Prefer the documented HyperFrames workflow. Read the runtime references before claiming support. Actual video checks and inspected frames are required before delivery. No Git push or publication is implied. No subagents are needed unless the user requests them.
